# MBP Marktüberblick

Prototyp für die Bewerbung im Projektteam IT des Münsteraner Börsenparkett.

Start: `python daten_holen.py --beispiel && python bauen.py`, dann `dashboard.html` im Browser öffnen.

Mit Claude Code weiterarbeiten: Ordner öffnen und `claude` starten. Die Datei `CLAUDE.md` erklärt Aufbau, Befehle und nächste Schritte.
